🔗 الربط بـ Google Drive

غير متصل
  1. انسخ السكربت بعد كتابة كلمة السر.
  2. افتح script.google.com ↗ بحساب Google الذي ستُحفظ فيه الرولات، فيُفتح مشروع جديد. امسح المكتوب، والصق السكربت، واضغط 💾 حفظ.
  3. من القائمة العلوية اختر الدالة setup واضغط ▶ تشغيل. عند طلب الصلاحيات: مراجعة الأذونات ← اختر حسابك ← Advanced / خيارات متقدمة ← Go to … (unsafe) ← Allow / سماح.
  4. اضغط نشر (Deploy) ← نشر جديد ← ⚙️ النوع: تطبيق ويب (Web app)
    • التنفيذ باسم: أنا (Me)
    • من يمكنه الوصول: أي شخص (Anyone)
    ثم نشر.

🌐 الإعداد الموحد للنسخة المنشورة (config.js)

—

بعد نجاح الاتصال اضغط الزر لتنزيل ملف config.js، ثم ارفعه على GitHub بجوار admin.html وuser.html. بعدها يعمل التطبيق عند الجميع مباشرة بدون كود ربط.

🔒 الملف لا يحتوي أي كلمة سر، لأن ملفات GitHub يراها الجميع. كلمة سر المسؤول تُكتب مرة واحدة على جهاز المسؤول فقط. ولو وضعت كلمة سر للاطلاع، فسيكتبها كل مستخدم مرة واحدة على جهازه.
